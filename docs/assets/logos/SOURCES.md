# Conference logo sources

- NeurIPS: https://neurips.cc/media/Press/NeurIPS_logo.svg (official media kit: https://neurips.cc/public/MediaKit). Added an intrinsic viewBox matching the supplied width and height so the original artwork scales without distortion.
- ICLR: https://iclr.cc/static/core/img/ICLR-logo.svg (linked by the official conference homepage: https://iclr.cc/). Artwork unchanged.

Logos identify publication venues; rights remain with their respective organizations.

## Social icons

LinkedIn, Instagram, Google Scholar, and X icons from Simple Icons v11.15.0, embedded as inline SVGs in the homepage. Source: https://github.com/simple-icons/simple-icons/tree/11.15.0/icons (CC0). Original path geometry retained; displayed in the site text color.
